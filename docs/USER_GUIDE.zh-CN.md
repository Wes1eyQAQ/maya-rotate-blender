# 使用指南

选择物体或姿态骨骼后，在 3D 视图按 N，进入 Maya → Stable Rotate，点击 Use Maya Rotate 1.9。

| 拖动位置 | 功能 |
| --- | --- |
| 红、绿、蓝圆环 | 工具 X、Y、Z 轴旋转 |
| 球内部 | 自由三维旋转 |
| 黄色外圈 | 绕视线旋转 |

按住 Shift 精细调整。松开左键或按 Enter 确认，Esc 或右键取消。开启自动打帧时，确认后只插入旋转通道的关键帧。

Sphere Size 是球的大小。激活此工具后，+ / - 和数字小键盘加减可以调整大小。

Opacity 是透明度，Color Saturation 是颜色饱和度，Line Width 是线条粗细。Reset Appearance 重置这三项，不重置大小。饱和度调整保持色相与亮度，不把颜色变成黑白。

在 Blender 坐标方向下拉框中选 Global、Local、View 或自定义方向；其他方向当前回退到全局。这是工具方向，不是修改骨骼静置轴。

球没有出现时，检查是否点击了启用按钮、选中了目标，以及工具 Gizmo 是否可见。升级后重启 Blender。支持物体与姿态模式，不支持编辑模式。

多个目标各自原地旋转，不绕共享枢轴公转。约束、驱动仍可能影响最终结果。可先用无约束物体检查工具行为。
