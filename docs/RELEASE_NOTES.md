# v1.9.1 — First public release

- Axis rings with continuous edge-on dragging.
- Free sphere rotation and a yellow view-direction ring.
- Rotation-only transforms and auto-keying for objects and pose bones.
- Sphere resizing with + / -, opacity, saturation and line width controls.
- English default and English/Chinese/Japanese switching.
- Fix a misplaced panel-layout call in the sphere draw callback before public packaging.

Validated with Blender 4.4.3 on Windows. Automated checks exercise math, modal behavior and data preservation; visual hit-testing still requires UI testing.
